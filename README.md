# MiniTorch

Реализованы базовые операции, автоматическое дифференцирование и работа с тензорами. Для ускорения добавлены операции с Numba и ядра CUDA.

Проверки охватывают значения функций, градиенты, индексацию и матричное умножение. Проверки CUDA в симуляторе проверяют результат вычислений. Скорость на настоящей видеокарте они не измеряют.

Короткие локальные проверки прошли. Результаты полного обучения сохраняются отдельно.
